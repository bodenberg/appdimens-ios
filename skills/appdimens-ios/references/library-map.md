# Library map

| Need | Product/import | Main API |
|---|---|---|
| Complete library | `AppDimensDynamic` | all exports |
| Core scaling | `AppDimens` | `sdp`, `hdp`, `wdp`, `ssp`, `ScaledDp` |
| Curves | `AppDimensStrategies` | `DynamicDimens`, `StrategyOptions` |
| Conditions | `AppDimensAuto` | `AutoDp`, `AutoSp` |
| Fit candidates | `AppDimensResize` | `DimensResize` |
| Units | `AppDimensUnits` | `DimensUnits` |
| GPU uniforms | `AppDimensMetal` | `AppDimensUniforms`, `AppDimensMetal` |

Source of truth: `Package.swift` and declarations under `Sources/`. User docs: `Documentation/README.md`.
