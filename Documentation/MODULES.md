# Modules

[Documentation hub](README.md) · [API](API.md)

| Product | Depends on | Contents |
|---|---|---|
| `AppDimens` | — | configuration, metrics, ambient store, kernels, builders, scaled catalog, SwiftUI/UIKit/AppKit integration |
| `AppDimensStrategies` | `AppDimens` | `StrategyOptions`, `DynamicDimens`, `dynamic(_:)`, `DimensFactors` |
| `AppDimensPercent`, `AppDimensPower`, `AppDimensFluid`, `AppDimensAuto`, `AppDimensDensity`, `AppDimensDiagonal`, `AppDimensFill`, `AppDimensFit`, `AppDimensInterpolated`, `AppDimensLogarithmic`, `AppDimensPerimeter` | `AppDimens` (+ strategies for most) | generated catalog for one strategy + builders |
| `AppDimensResize` | `AppDimens` | resize bounds and ladders |
| `AppDimensUnits` | `AppDimens` | physical units |
| `AppDimensCustom` | `AppDimens` | user-defined strategies: engine, `ScalingStrategy.define`, JSON (shared format), presets, `cdp`/`csp`, `@CustomDimension`, `.scalingStrategy(_:)` — see [custom.md](strategies/custom.md) and [custom/](strategies/custom/README.md) |
| `AppDimensMetal` | `AppDimens`, `AppDimensStrategies` | GPU uniforms, MSL source, encoder helpers |
| `AppDimensDynamic` | all of the above except the satellite catalogs | aggregate import |

Catalogs are generated by `scripts/generate_catalogs.py`; CI fails if they are out of date.
