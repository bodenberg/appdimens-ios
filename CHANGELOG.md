# Changelog

## 3.0.0

- Rebuilt the obsolete project as a native Swift value-type engine.
- Split platform-neutral `AppDimens` and UI adapter `AppDimensUI` modules.
- Added container-aware SwiftUI environment, property wrapper and modifiers.
- Added UIKit trait/context integration.
- Added Android-familiar fluent declarations and typed qualifier intersections.
- Added deterministic Dynamic Type, pixel rounding, limits, percentage and item utilities.
- Added cross-platform tests and full architecture/API/migration documentation.
